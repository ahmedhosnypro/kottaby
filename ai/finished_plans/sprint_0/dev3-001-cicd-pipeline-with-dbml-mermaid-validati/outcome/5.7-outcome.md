## GitHub native isolation statement (REQ-033 mapping)
GitHub Actions caches saved from a `pull_request` event run are scoped to the branch namespace: they can be RESTORED by the same PR's subsequent runs, but are **never restored into `develop`/`main` runs** until an event on those branches saves its own entry. This native isolation satisfies REQ-033 without extra logic; combined with content-addressed keys (`hashFiles('bun.lock')`) and append-only `${{ github.run_id }}` save keys, cache-poisoning surface stays closed (pairs with 6.W4 pentester re-check).
