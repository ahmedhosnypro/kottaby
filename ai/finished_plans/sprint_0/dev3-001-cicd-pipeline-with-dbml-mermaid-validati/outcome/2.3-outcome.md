**Design decisions recorded (all asserted in tests):**
1. Everything side-effecting is injected through the `DocsCiIo` interface; `createProductionIo()` captures ALL env-dependent inputs (`EVENT_NAME`, `BASE_REF`, `GITHUB_STEP_SUMMARY`) at the `import.meta.main` boundary — the core reads NO globals (test proves parameter-over-env precedence).
2. Pr-mode git failure surfaces the child stderr VERBATIM and UN-TRUNCATED behind an attributed prefix line, then propagates git's own exit code (e.g. 128) — a broken checkout can never masquerade as an empty green set (REQ-026).
3. Push-mode sort = arithmetic relational comparator `Number(a>b)-Number(a<b)` — UTF-16 code-unit deterministic without ternary chains or locale involvement.
4. Entry discipline preserved from sibling scripts: zero `console.*`, English-only operator strings (REQ-002 exemption, §7), strict typed exports, no `import type` misuse, `@/scripts/ci/changed-docs` alias import per repo lint rule (plan offered either form).
