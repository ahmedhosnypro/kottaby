Key contracts delivered:

- DomainError pass-through preserves localized `message`, producer extensions,
  taxonomy-normalization is delegated downstream; `ctx.requestId` attached;
  ValidationError `fields` mirrored only when present (absent/empty/populated
  discrimination per REQ-015).
- One-hop local unwrap (`originalError`/`cause`) only; deep traversal reused via
  shipped cycle-guarded `translateDbError` (single delegation point, pinned by a
  hygiene test that fails if the import count changes). **No second cause-walker**
  (zero `while` loops in the module).
- Masks carry dev-only `extensions.debug` diagnostics snapshot (stripped under
  PROD runtime), are deterministic byte-for-byte, and preserve caller
  `path`/`locations`.
- `redactLogContext`: bounded (depth 6 / items 64 with explicit markers),
  credential-key-pattern redaction (token/password/secret/key/auth/bearer/
  meeting-provider/WhatsApp families + Authorization-shaped values),
  prototype-pollution immune, exotic-safe (bigint/symbol/throwing getters).
- Finalizer emits exactly one correlated log per non-domain element via
  `@/backend/lib/logger` (`[ERROR]` mask line); zero-op results return the
  IDENTICAL reference.
