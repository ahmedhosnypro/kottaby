Warnings side:
- B1/B2: partial-success execution puts warnings INSIDE `data`

  {success:true, warning:"…"}`) with `errors === undefined`; B1 additionally pins whole-key-set

  pinned to the mutation field and warning text asserted ABSENT from the serialized error item
  (channel separation). A4 proves the same helper end-to-end over HTTP through route + finalizer.
