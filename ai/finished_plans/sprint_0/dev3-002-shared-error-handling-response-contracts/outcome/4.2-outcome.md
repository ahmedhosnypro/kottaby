## Component API surfaces

### `PermissionDeniedFallback`

```tsx
interface PermissionDeniedFallbackProps {
  readonly title?: string;       // override; default = errors.forbiddenRole
  readonly description?: string; // override; default = errors.forbidden
}
```

- Centered full-width container wrapping ONE MUI v9 `<Alert>` card (`maxWidth: 520`, breakpoint-aware `px/py`).
- `icon={<LockOutlined … />}` (`*Outlined` per MUI v9 rename rule); title/description hierarchy via `AlertTitle` + `Typography`.
- **Never returns bare `null`** — always renders the localized fallback (frontend/AGENTS.md a11y rule).

### `RetryableNotice`

```tsx
type RetryableNoticeKind = "RATE_LIMITED" | "SERVICE_UNAVAILABLE";
interface RetryableNoticeProps {
  readonly kind: RetryableNoticeKind;
  readonly onRetry?: () => void;
  readonly retryInFlight?: boolean; // prop-driven; button disabled while true (+ spinner startIcon)
}
```

- Severity lookup table `KIND_SEVERITY`: `RATE_LIMITED → warning`, `SERVICE_UNAVAILABLE → error` (**error/warning ONLY**); message from `errors.rateLimitExceeded` / `errors.serviceUnavailable` (canonical names per 1.2-outcome — there is NO `rateLimited` key); button label from `common.retry`.
- Root `Alert` carries `aria-busy={retryInFlight}`; retry affordance inline via the `action` slot with `RefreshOutlined`.

### `fieldError.ts` (pure, React-free)

| Export | Purpose |
|---|---|
| `FieldErrorContractEntry` | Structural mirror of wire shape `{ field, code?, message }` |

## Decisions recorded

1. **Announce semantics (correction #8):** both surfaces ARE MUI v9 Alerts. MUI v9 `Alert` sets `role="alert"` internally by default (`node_modules/@mui/material/Alert/Alert.js:165` `role = 'alert'`). Per R1 #8 ("or an actual MUI Alert") and `frontend/AGENTS.md` ("Use `<Box component="alert">` instead of `role="alert"` on NON-Alert elements"), neither a literal `role` nor an extra `component="alert"` root-tag override is added — no lint exposure, announce semantics intact, DOM stays a semantic `<div role="alert">`.
2. **Copy keys:** page-deny title uses `errors.forbiddenRole` per the 1.2-outcome carry-forward ("permission-denied fallback should continue using forbiddenRole"); description defaults to `errors.forbidden`; overrides accepted as props for query-level vs section-level contexts.
3. **i18n access:** `useAppTranslation(Errors)` / `useAppTranslation(Common)` handle objects from `@/shared/locale` barrel (the R1-sanctioned mapping of the plan's "`Translation.<Namespace>` enum"), property access only, zero string-literal namespaces, zero hardcoded copy.
4. **Styling:** `sx`-only everywhere (no direct style props); colors exclusively via theme callbacks (`error.main`, `errorContainer`, `onErrorContainer` M3 siblings) or semantic `severity`/`color` props mapped through theme — zero hex/rgb/named-color literals; icons `*Outlined` only.
