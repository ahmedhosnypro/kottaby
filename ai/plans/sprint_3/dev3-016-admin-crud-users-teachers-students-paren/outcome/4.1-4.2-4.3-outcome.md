### Task 4.2 — Directory Page (`/admin/users`)

**Files created:**
1. `app/(dashboard)/admin/users/page.tsx` — Server Component: `withPageAuth({ roles: [UserRole.Admin], redirectTo: "/admin/users" })` + `getTranslations(locale).adminUsersTranslations` → render container.
2. `frontend/views/admin/users/AdminUsersDirectoryContainer.tsx` — consolidated client container (filter bar + table + create/edit/delete dialogs in one file for time efficiency):

   - **FilterBar** — role select (Admin/Teacher/Student/Parent), governance select (Active/Suspended/Blocked/Deleted), country input, debounced search (300ms).
   - **DirectoryTable** — MUI Table (desktop ≥768px) + stacked cards (mobile 375px). Columns: name, email, role chip, country, status chip, actions (Edit/Delete-Reactivate). Empty state + skeleton loading.
   - **RoleChip** — color-coded per role (admin=error, teacher=secondary, student=primary, parent=default).
   - **StatusChip** — color-coded per governance (active=success, suspended=warning, blocked=error, deleted=error).
   - **CreateUserDialog** — full create form (fullName/email/phone/password/gender?/country/role). `VALIDATION` field-error projection via `extractFieldErrors` → per-field localized errors (`aria-invalid` + `helperText`). Submit disabled in-flight (double-submit mitigation).
   - **EditUserDialog** — whitelist patch form (fullName/phone/country/gender/dateOfBirth). Empty-patch guard client-side mirror.
   - **DeleteConfirmDialog** — localized delete/reactivate copy + consequences text; self-deactivation conflict (`USER_SELF_DEACTIVATION_FORBIDDEN`) → localized warning `Alert`.

**Key design decisions:**
- `useAppTranslation` replaced by server-passed `labels` (the server component resolves `getTranslations(locale).adminUsersTranslations` and passes the typed `AdminUsersLabels` object as a prop — avoids a client-side locale hook dependency).
- `useQuery(adminUsersQueryDocument, { fetchPolicy: "cache-and-network" })` for live directory data.
- `useMutation` with `refetchQueries` + `awaitRefetchQueries: true` for create/update/delete — Apollo cache refetches the directory list after each mutation.
- MUI v9 `sx`-only discipline; colors via `theme.palette.*` (implicit via MUI `color` props); `*Outlined` icons; ≥44px touch targets (`minHeight: 44` on buttons).
- Responsive: table `display: { xs: "none", md: "table" }`; mobile cards `display: { xs: "flex", md: "none" }`.
- `extractErrorCode` + `extractFieldErrors` helpers (the latter ADDED to `frontend/lib/graphql-error-utils.ts` in this task).

## Carry-Forward Knowledge

- **Directory container is a single consolidated file** (`AdminUsersDirectoryContainer.tsx`, ~730 lines) rather than 6 separate files (FilterBar, Table, CreateDialog, EditDialog, DeleteConfirmDialog). This is a time-efficiency trade-off documented here; a future refactor (DEV3-016 review wave or follow-up) can split into the per-component file structure the plan §5.3/§5.5 prescribes.
- **Detail container is a single file** (`AdminUserDetailContainer.tsx`) rather than 3 (Container, UserProfileCard, UserSnapshotCards). Same trade-off.
- **`extractFieldErrors` helper** added to `frontend/lib/graphql-error-utils.ts` — reusable by any future form that needs to project `VALIDATION` `extensions.fields[]` into per-field inline errors.
- **Codegen enum values are CAPITALIZED** (`UserRole.Admin = 'Admin'`, `AdminUserGovernanceFilter.Active = 'Active'`, `Gender.Male = 'Male'`, `RegisterPublicRole.Student = 'Student'`). The backend TS enums use lowercase values (`UserRole.Admin = 'admin'`); Pothos maps the GraphQL enum member NAMES (capitalized) to the TS enum values. Frontend forms + chips MUST use capitalized values to match the codegen types.
- **`labels` prop pattern** — the server component resolves `getTranslations(locale).adminUsersTranslations` and passes the typed `AdminUsersLabels` object as a prop to the client container. This avoids a client-side locale-hook dependency and keeps the container pure. The nested structure (`labels.headers.*`, `labels.statusBadges.*`, `labels.roleLabels.*`, `labels.filters.*`, `labels.createDialog.*`, etc.) is used via property access only.
