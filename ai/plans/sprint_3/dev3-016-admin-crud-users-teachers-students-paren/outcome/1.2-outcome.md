```ts
export enum AdminUserGovernanceFilter {
  Active = "active",
  Suspended = "suspended",
  Blocked = "blocked",
  Deleted = "deleted",
}

export function isAdminUserGovernanceFilter(
  value: unknown,
): value is AdminUserGovernanceFilter {
  return (
    typeof value === "string" &&
    (Object.values(AdminUserGovernanceFilter) as string[]).includes(value)
  );
}
```

### File docstring documents the two-channel fail-closed split

The enum file's module-level JSDoc explains the intentional split:
1. **Loose read path (service-layer directory listing)**: an unknown `governance` filter value falls back — the filter is dropped, the directory returns the unfiltered listing. `isAdminUserGovernanceFilter` returns `false` on unknown strings without `as` casts; the service treats `false` as "no filter supplied".
2. **Strict input path (GraphQL input field)**: a transport-tampered value that fails Pothos enum-coercion at parse time yields `VALIDATION` BEFORE any DB read. The mutation/input channel remains strict.

This split preserves the directory listing as a forgiving read surface (callers don't get errors when an old client sends a now-retired enum value) while the input channel (create/update/delete) remains strict and surfaces malformed input as `VALIDATION`.

## 1.2.SEC — Security & Tenancy Audit

### Guard rejects arbitrary strings without `as` casts

```ts
export function isAdminUserGovernanceFilter(
  value: unknown,
): value is AdminUserGovernanceFilter {
  return (
    typeof value === "string" &&
    (Object.values(AdminUserGovernanceFilter) as string[]).includes(value)
  );
}
```

- **NO `as AdminUserGovernanceFilter` cast on `value`**: the guard returns `false` (rather than throwing) for non-string inputs, unknown strings, case variants, and whitespace.
- **The `as string[]` cast** is on `Object.values(AdminUserGovernanceFilter)` (the enum's own value array, which TypeScript types as `AdminUserGovernanceFilter[]`) — necessary because `Array.prototype.includes()` requires the search argument's type to match the array element type. This is the canonical pattern used by the existing codebase (`isApplicantStatus` at `backend/enum/teachers/applicant-status.enum.ts:25`, `isRecitationReading` at `shared/constants/recitation-reading.enum.ts:78`). It casts the ENUM'S OWN VALUE LIST to a string array, NOT the input value — it's safe.
- **Membership check via `Object.values(...).includes(...)`** keeps the guard in sync with the enum's runtime value set; no parallel hard-coded literal list that could drift from the enum. Adding a new member to `AdminUserGovernanceFilter` automatically extends the guard's recognized set.

### Two-channel fail-closed split (documented in the file docstring)

- **Loose read path (service-layer directory listing filter)**: an unknown `governance` value yields `isAdminUserGovernanceFilter(value) === false`; the service treats this as "filter not supplied" and returns the unfiltered directory (no error). This preserves the directory as a forgiving read surface.
- **Strict input path (GraphQL input field)**: when `AdminUserGovernanceFilter` is registered as a Pothos enum (Task 3.1), a transport-tampered value that is not a recognized member fails enum-coercion at parse time, producing a `VALIDATION` error BEFORE any DB read.

Both behaviors are documented in the enum file's module-level JSDoc under "Fail-closed semantics (two-channel split)".

### For Task 2.3 (directory listing service — `listDirectory`)

The service MUST consume the enum at runtime to build the predicate conjunction:

```ts
// Inside AdminUserManagementService.listDirectory:
let governanceFilter: AdminUserGovernanceFilter | null = null;
if (input.governance != null) {
  if (isAdminUserGovernanceFilter(input.governance)) {
    governanceFilter = input.governance;  // narrow via the guard
  }
  // else: drop the filter (return the unfiltered directory) — fail-closed
}

// Build the predicate:
const conditions = [];
if (governanceFilter === AdminUserGovernanceFilter.Active) {
  conditions.push(
    and(
      or(eq(users.isDeleted, false), isNull(users.isDeleted)),
      or(eq(users.suspended, false), isNull(users.suspended)),
      or(eq(users.isBlocked, false), isNull(users.isBlocked)),
    ),
  );
} else if (governanceFilter === AdminUserGovernanceFilter.Suspended) {
  conditions.push(
    and(
      or(eq(users.suspended, true)),
      or(eq(users.isDeleted, false), isNull(users.isDeleted)),
      or(eq(users.isBlocked, false), isNull(users.isBlocked)),
    ),
  );
} else if (governanceFilter === AdminUserGovernanceFilter.Blocked) {
  conditions.push(eq(users.isBlocked, true));
} else if (governanceFilter === AdminUserGovernanceFilter.Deleted) {
  conditions.push(eq(users.isDeleted, true));
}
// else: governanceFilter === null → no governance predicate → return unfiltered
```

**Important — never use raw string literals** like `"active"` / `"suspended"` in the predicate switch — always compare to `AdminUserGovernanceFilter.Active` etc.
