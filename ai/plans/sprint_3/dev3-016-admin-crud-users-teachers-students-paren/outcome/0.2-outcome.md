- **Verified engine behavior (lines 88–95):**
  > - `{ role: [UserRole.Teacher] }` **alone** is wrong: anonymous → FORBIDDEN instead of UNAUTHORIZED.

  > - `$all` makes the conjunction explicit: anonymous → the `authenticated` scope's thrown `UnauthorizedError` passes through the mapping verbatim → `UNAUTHORIZED` (401); authenticated non-teacher → role scope false → canonical localized `ForbiddenError` → `FORBIDDEN` (403).
- **Carry-forward for Task 3.2:** Every new admin operation MUST use `authScopes: { $all: { authenticated: true, role: [UserRole.Admin] } }` — plain key-map = ANY semantics = WRONG (D10 binding). Anonymous → 401; authenticated non-admin → 403 (REQ-030 / REQ-062).
