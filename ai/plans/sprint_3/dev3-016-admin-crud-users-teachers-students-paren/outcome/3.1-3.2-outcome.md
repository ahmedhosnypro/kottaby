**Files modified:**

**Key design decisions:**
- EVERY operation carries EXACTLY `authScopes: { $all: { authenticated: true, role: [UserRole.Admin] } }` (D10 — `$all` conjunction; plain key-map = ANY semantics = FORBIDDEN pattern).
- Resolver bodies are thin: ID arg → `requirePositiveIntId` guard (no `as number`) → service call with `(…, ctx.user.id, ctx.locale)` → return. Resolvers throw NOTHING directly; service `DomainError` subclasses propagate with `extensions.code` and boundary masking.
- Reads (`adminUsers`, `adminUserDetail`) pass `ctx.user.id` as `actorId` for defense-in-depth (the service's `assertActorAdmin` checks the actor is an admin, beyond the GraphQL authScope).
- `resolvePagination` helper enforces `page >= 1`, `pageSize` in `1..100` (defaults: page=1, pageSize=25).
